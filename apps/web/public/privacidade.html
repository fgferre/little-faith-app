little faith

Política de privacidade

Atualizada em 16 de outubro de 2026.

O Little Faith · Bolões é um app gratuito para organizar bolões de loteria entre amigos. O dinheiro não passa pelo app: quem paga a cota faz o Pix direto para o tesoureiro da turma, que faz o jogo na lotérica ou no app da CAIXA. Esta página explica quais dados o app guarda, para quê e como pedir que sejam corrigidos ou apagados.

Quem é o responsável

O app é feito e mantido pela Pipo Labs, de Felipe Ferreira. Para qualquer assunto sobre os seus dados, escreva para fgferre@gmail.com.

Que dados o app guarda

  • De quem organiza ou é tesoureiro: o nome, o e-mail e o identificador da conta Google, usados só para você entrar no app. O app não acessa nenhum outro dado da sua conta Google.
  • Do grupo e dos bolões: o nome do grupo, os nomes e apelidos das pessoas, a declaração de que são maiores de idade, as cotas, os pagamentos registrados (valor, data e referência bancária, se informada), os jogos, os bilhetes e comprovantes enviados (foto ou PDF), os resultados e a divisão do prêmio.
  • Telefone (WhatsApp) de cada pessoa, quando quem organiza decide cadastrar, para abrir a conversa com ela. Só quem organiza o grupo vê; o telefone nunca aparece no cartão de quem participa.
  • De quem participa: não é preciso criar conta. O cartão de cada pessoa abre por um link pessoal. O app guarda apenas uma versão embaralhada desse link e, se a pessoa criar um, do PIN do cartão; não é possível recuperar o link nem o PIN a partir dela.

Para que os dados são usados

Só para o bolão funcionar: lembrar quem ainda não respondeu, mostrar a cada pessoa o seu cartão, registrar pagamentos, conferir os bilhetes com o resultado e calcular a parte de cada um. Os dados não são vendidos, alugados nem usados para anúncios. O app não tem anúncios nem ferramentas de rastreamento ou estatística de uso.

Onde os dados ficam

  • No seu aparelho, no navegador, para o app funcionar mesmo sem internet.
  • No Supabase, o serviço de banco de dados do app, em servidores em São Paulo. Os comprovantes ficam num armazenamento privado.
  • O app em si é servido pelo GitHub Pages.

Com quem os dados são compartilhados

Com ninguém além dos serviços que mantêm o app funcionando: o Google, para a entrada com a sua conta; o Supabase, para guardar os dados; e o GitHub, para servir o app. O resultado oficial e o prêmio estimado de cada concurso são buscados pelo seu próprio aparelho direto no site da CAIXA, como numa visita comum ao site dela. As mensagens para a turma saem pelo seu WhatsApp, quando você escolhe enviar.

Dados de outras pessoas

Quem organiza cadastra os dados da turma no app. Faça isso com o conhecimento das pessoas e cadastre só o necessário para o bolão.

Seus direitos

Pela Lei Geral de Proteção de Dados (LGPD), você pode pedir para ver, corrigir ou apagar os seus dados. Quem organiza corrige os dados da turma no próprio app e pode baixar uma cópia do grupo em Dados. Para apagar, escreva para fgferre@gmail.com: o pedido é atendido em até 30 dias, guardando apenas o que a lei obrigar.

Por quanto tempo os dados são guardados

Enquanto o grupo usar o app. Registros de dinheiro e de jogos não são apagados por engano: ficam até que você peça a exclusão.

Só para maiores de 18 anos

Loterias são permitidas só para maiores de 18 anos, e o app também.

Mudanças nesta política

Se esta política mudar, a nova versão aparece nesta página, com a data de atualização.
